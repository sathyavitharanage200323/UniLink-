## Testing the System

### As a Student:
1. Login with any student email (e.g., tharindu.j@student.uoc.lk)
2. Navigate to "Book Appointment"
3. Select a lecturer
4. View their availability grid
5. Book an appointment

### As a Lecturer:
1. Login with any lecturer email (e.g., nimal.perera@uoc.lk)
2. Navigate to "Appointment Triage Dashboard"
3. View pending requests (Year 4 students appear at top)
4. Accept/Decline/Reschedule appointments
5. For confirmed appointments: Mark as completed or delay meeting
6. Navigate to "Manage Availability" to set your weekly schedule

## New Features Implemented

### Delay and Reschedule Functionality
- **For PENDING appointments**: Lecturers can request reschedule with new date/time and reason
- **For CONFIRMED appointments**: Lecturers can delay meetings by 15/30/45/60 minutes with reason
- Both actions trigger email notifications to students (simulated via console.log)
- Backend endpoint: `PATCH /api/appointments/{id}/time` with startTime and endTime

### Backend Changes
- Added `updateTime()` method in AppointmentService
- Added `/time` endpoint in AppointmentController
- Supports ISO datetime format for time updates

### Frontend Changes
- Reschedule form: date picker, time picker, reason textarea
- Delay form: duration dropdown (15/30/45/60 min), reason textarea
- Loading states and validation
- Automatic page refresh after successful update
